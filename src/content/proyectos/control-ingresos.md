Sistema desarrollado para automatizar el ingreso de personal externo a una empresa: valida solicitudes, notifica por correo automáticamente y deja trazabilidad de cada acceso, reduciendo cuellos de botella y mejorando la seguridad frente a un proceso manual.

Incluye inicio de sesión corporativo con cuenta Microsoft 365, para que cada colaborador entre con la misma cuenta que ya usa en la empresa, sin crear un usuario adicional.

El frontend está construido en React y el backend en Laravel con MySQL, comunicados a través de una API REST.
